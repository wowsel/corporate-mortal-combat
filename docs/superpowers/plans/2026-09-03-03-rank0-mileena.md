# Этап 3: Ступень 0 «Стажёр» — Милина — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Первая настоящая ступень карьеры: два события онбординга и собеседование-бой с Милиной из HR, с реальным фоном опенспейса, портретами и спрайтами. Dev-заглушка ступени 0 удаляется.

**Architecture:** Контент ступени — один файл `src/content/ranks/00-intern.ts`, подключаемый в `src/content/index.ts`. Ассеты ступени — записи группы `rank0` в `assets/manifest.json`, генерируются пайплайном этапа 2. Движок не меняется.

**Tech Stack:** тот же, что на этапах 1–2. Генерация: `npm run gen -- --group rank0`.

**Spec:** `docs/superpowers/specs/2026-09-03-corporate-mortal-kombat-design.md`

## Global Constraints

- Ступень не последняя: ровно 2 события, 2–4 варианта в каждом, первый вариант без `requiresFlag`, каждый `requiresFlag` кем-то ставится.
- Милина: терпение 90, атака 10, слабость `joke`, иммунитет `blame`, `final: false`. Текст события перед боем содержит намёк на слабость и иммунитет.
- Фон ступени один: `bg_openspace` (1600×900, 2K). Портреты 512×512, спрайты 700×900, маджента `#FF00FF`, босс смотрит **влево** (герой вправо).
- Порядок генерации: портрет neutral → idle → attack/hurt/defeated (референсы: стиль + портрет + idle) и портрет angry (референс: neutral).
- Все реплики и тексты на русском, тон — офисная сатира без грубости.
- Коммит после каждой задачи.

```ts
import { describe, expect, it } from 'vitest';
import { CONTENT } from '../src/content';
import { MOVES } from '../src/content/moves';

const HINT_WORDS: Record<string, RegExp> = {
  agree: /соглас|лоял|кива/i, data: /данн|цифр|график|отчёт/i, blame: /вин|стрелк|ответствен/i, joke: /юмор|шут|смеш/i,
};

describe('content hints', () => {
  it('текст перед боем намекает на слабость и иммунитет босса', () => {
    for (const r of CONTENT.ranks) {
      // у ступени без событий (финал) намёк даёт вступительная реплика босса
      const last = r.events[r.events.length - 1];
      const blob = last
        ? `${last.text} ${last.repeatText ?? ''} ${last.choices.map(c => c.text + (c.reaction?.text ?? '')).join(' ')}`
        : r.boss.intro;
      expect(blob, `${r.id} weakness ${r.boss.weakness}`).toMatch(HINT_WORDS[r.boss.weakness]!);
      expect(blob, `${r.id} immunity ${r.boss.immunity}`).toMatch(HINT_WORDS[r.boss.immunity]!);
    }
    expect(MOVES.map(m => m.id).every(id => id in HINT_WORDS)).toBe(true);
  });
});
```
