# Этап 6: Ступень 3 «Руководитель направления» — Синдел — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Четвёртая ступень карьеры: два события руководителя направления (защита проекта бюджета и найм сотрудника) и бой-защита бюджета перед финансовым директором Синдел, с реальным фоном зала совета, портретами и спрайтами. Первая ступень, на событиях которой звучит `mu_council`.

**Architecture:** Контент ступени — один файл `src/content/ranks/03-lead.ts`, подключаемый в `src/content/index.ts`. Ассеты ступени — записи группы `rank3` в `assets/manifest.json`, генерируются пайплайном этапа 2. Движок не меняется: переключение музыки на `mu_council` при `rank >= 3` уже заложено в экране событий на этапе 2.

**Tech Stack:** тот же, что на этапах 1–5. Генерация: `npm run gen -- --group rank3`.

**Spec:** `docs/superpowers/specs/2026-09-03-corporate-mortal-kombat-design.md`

## Global Constraints

- Ступень не последняя: ровно 2 события, 2–4 варианта в каждом, первый вариант без `requiresFlag`, каждый `requiresFlag` кем-то ставится. Доступные флаги предыдущих ступеней: `intern_joker` (ступень 0), `baraka_respect` (ступень 1), `kitana_owes_you` (ступень 2). Ступень ставит новый флаг `sindel_budget_ally`.
- Синдел: терпение 170, атака 13, слабость `blame`, иммунитет `joke`, `final: false`. Текст события перед боем содержит намёк на слабость (`/вин|стрелк|ответствен/i`) и иммунитет (`/юмор|шут|смеш/i`) — проверяется тестом `content.test.ts` этапа 3.
- Эффекты выбора в пределах ±15 на стат, дельты стресса небольшие (±5..10).
- Фон ступени один: `bg_council` (1600×900, 2K). Портреты 512×512, спрайты 700×900, маджента `#FF00FF`, босс смотрит **влево** (герой вправо).
- В промптах ни слова про розовый, пурпурный или маджентовый цвет одежды: фирменный цвет Синдел описывается как «deep indigo / dark violet». Белые волосы на мадженте — риск розовой каймы, поэтому в `idle` волосы компактные, движение оставлено позам `attack` и `hurt`.
- Порядок генерации: портрет neutral → idle → attack/hurt/defeated (референсы: стиль + портрет + idle) и портрет angry (референс: neutral).
- Все реплики и тексты на русском, тон — офисная сатира без грубости.
- Dev-заглушка финальной ступени (`dev1`, `dev_shao`) остаётся до этапа 8.
- Коммит после каждой задачи.
