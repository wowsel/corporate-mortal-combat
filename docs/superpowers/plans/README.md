## Этап 1 выполнен — заметки для этапа 2

Перенесено из ledger финального ревью этапа 1 (всё остальное закрыто):

- `assets/manifest.json` импортируется в браузерный бандл целиком; при появлении промптов нужен runtime-срез (только `id, kind, group, file, size, anchor, duration`).
- Музыка: fade-out `setTargetAtTime(0, t, 0.4)` при `stop(t + 1.2)` оставляет ~5% амплитуды (щелчок); старые source-узлы не отключаются. Проверить на первом реальном `mu_*`.
- Титул: `playMusic('mu_title')` вызывается по клику, а не при монтировании — после рестарта музыка концовки продолжает играть на титуле; звук разблокируется по кнопке «Начать», кнопки mute на титуле нет.
- Контракт `AssetStore` описан в `src/assets.ts` — реальный загрузчик обязан его соблюдать (`loadGroup` не реджектится, прогресс монотонный до 1, `getTexture` никогда не null, `getImageUrl` — null или URL, безопасный в `url('…')`).
- Проверить кадрирование камеры при zoom 1.4 на реальных спрайтах с якорем в ногах (pivot в центре экрана).
- Полировка: пропуск печатающегося текста только мышью; `aria-label` кнопки mute не отражает состояние; `innerHTML` с контентными строками; favicon отсутствует.

## Этап 2 выполнен — заметки для этапов 3+

- Сгенерирован только герой (2 портрета + 4 спрайта, $0.34); финальный art-проход по титулу, концовкам, музыке и диктору отложен до утверждения сюжета.
- Финальная волна фиксов этапа 2 выполнена. Осталось отложенным (не блокирует): runtime-срез манифеста для бандла (промпты ≈ 9 КБ, пересмотреть после 50 КБ); pcm16-fallback в `tools/openrouter.ts` жёстко считает 24 кГц моно (только OpenAI); у аудио-записей нет raw, поэтому `--force` на музыке/голосе всегда тратит деньги; размер холста 700×900 зашит в `gen-assets.ts`; нет `../`-защиты в `refToDataUrl`; нет unit-тестов контракта `AssetStore`; в `check-assets` статус `deferred` определяется по пустому промпту.
- Известная тонкость автоключа: если фигура заметно (>~1 %) заходит на рамку, диагностика скажет «degenerate chroma key», а не «touches the frame border» — в обоих случаях смотреть raw и переснимать позу.
- Для планов 03–08 контентные задачи (события, диалоги, баланс) выполняются на заглушках как обычно; задачи генерации боссов пропускаются до общего art-прохода.
- Сгенерировать одного персонажа отдельно позже: `npm run gen -- --only id1,id2` (см. `README.md`, раздел «Ассеты»).
- Хромакей у `tools/postprocess.py` автооценивает цвет фона по рамке картинки, так что неидеальная маджента — не проблема; важно, чтобы фигура не касалась края кадра.

## Этап 3 выполнен — заметки для этапов 4+

- Сделаны задачи 1, 2 и 4 (на заглушках); задача 3 (генерация Милины и опенспейса, 7 записей `group: rank0`, `generated: false`) отложена до общего art-прохода. Промпты уже в манифесте, `npm run gen -- --dry-run --group rank0` показывает 9 записей (с `mu_office`, `mu_battle`) ≈ $0.48.
- Движок показывает только `lines.defeated[0]` (`choreo.ts`) — вторая реплика в `defeated` была бы мёртвым текстом; у боссов держать одну. `lines.hit` звучат и при ударе героя, и при обычной атаке босса — каждая фраза должна работать в обе стороны.
- Пузырь `intro` видно ~2 с до `FIGHT!` — держать до ~80 знаков. Реплики `special` идут крупным центрированным текстом ~1.4 с — до ~60 знаков.
- Тест `test/content.test.ts` ищет намёки на слабость и иммунитет только в `text` и `repeatText` последнего события (не в вариантах и реакциях): игрок видит одну реакцию из нескольких.
- Герой без пола: в текстах только формы на «вы» и без прошедшего времени/прилагательных к герою.
- Сквозные шутки, заведённые на ступени 0 (подхватывать, не повторять дословно): черепа как «инвентарь» и «полка» бывших сотрудников; кофе-машина сломана со времён Первой Династии, «заявка в работе»; слайд 47, которого не существует; Барака считает кивки — «у него по ним KPI» (задел на слабость `agree` ступени 1); Барака уже спрашивает в чате, кто вы (задел на «конфликт в чате» ступени 1); Китана — дочь генерального, ей «можно» (задел на ступень 2); регламент кофе-машины лежит в серверной-подземелье у Шанг Цунга, «за ним спускались трое» (задел на ступень 4). Милина — на «вы», Барака по плану 04 — на «ты».
- Флаг `intern_joker` ставится третьим вариантом первого события ступени 0.
- Баланс: на ступени 0 при игре по слабости герой поглощает 34–51 урона из 100 — ниже целевой полосы спеки 60–90; для первого босса это нормально, но учесть в симуляции этапа 8.
- Intro dev-финала (и будущее intro Шао Кана, план 08) сокращено до 78 знаков: «Пять минут. Меня не интересуют цифры. Меня интересует, кто со мной согласен.» — план 08 цитирует старую длинную формулировку, брать эту.
- `stylePrefix` говорит «shallow depth of field»; для фонов-планов в промпте явно переопределять глубину резкости (сделано в `bg_openspace`).
- Движок больше не зеркалит спрайт босса (`scene.ts`, было `new Fighter(BOSS_X, true, …)` со времён заглушек): боссы по спеке рисуются влево, поэтому промпты «facing LEFT» с `flip: false` верны; иначе после генерации босс смотрел бы от героя. Заглушки-прямоугольники симметричны, разница видна только на реальном арте.
