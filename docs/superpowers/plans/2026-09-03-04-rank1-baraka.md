# Этап 4: Ступень 1 «Младший специалист Внешнего Мира» — Барака — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Вторая ступень карьеры: два события в переговорке «Кровавый колодец» (квартальный обзор KPI и конфликт в чате) и код-ревью-бой с тимлидом Баракой, с реальным фоном переговорки, портретами и спрайтами. Появляется флаг `baraka_respect`, который используют следующие ступени.

**Architecture:** Контент ступени — один файл `src/content/ranks/01-junior.ts`, подключаемый в `src/content/index.ts` после `RANK_INTERN`. Ассеты ступени — записи группы `rank1` в `assets/manifest.json`, генерируются пайплайном этапа 2. Движок не меняется: ни `state`, ни `battle`, ни экраны, ни загрузчик — этап полностью «данные + картинки».

**Tech Stack:** тот же, что на этапах 1–3. Генерация: `npm run gen -- --group rank1`.

**Spec:** `docs/superpowers/specs/2026-09-03-corporate-mortal-kombat-design.md`

## Global Constraints

- Ступень не последняя: ровно 2 события, 2–4 варианта в каждом, первый вариант без `requiresFlag`, каждый `requiresFlag` кем-то ставится (`intern_joker` ставится на ступени 0, `baraka_respect` — в первом событии этой ступени).
- Барака: терпение 110, атака 11, слабость `agree`, иммунитет `joke`, `final: false`. Текст второго события содержит намёк на слабость (`/соглас|лоял|кива/i`) и иммунитет (`/юмор|шут|смеш/i`) — это проверяет тест `test/content.test.ts` из этапа 3.
- Эффекты варианта — в пределах ±15 по стату, стресс ±5..10.
- Фон ступени один: `bg_meeting_room` (1600×900, 2K). Портреты 512×512, спрайты 700×900, маджента `#FF00FF`, босс смотрит **влево** (герой вправо).
- В описании Бараки нет ни розового, ни маджентового, ни фиолетового: палитра — серый, бурый, оливковый, сталь. Иначе части персонажа уйдут в прозрачность при хромакее.
- Порядок генерации: портрет neutral → idle → attack/hurt/defeated (референсы: стиль + портрет + idle) и портрет angry (референс: neutral).
- Все реплики и тексты на русском, тон — офисная сатира без грубости.
- Dev-контент не трогаем: `dev0` удалён на этапе 3, финальный `dev1` с `dev_shao` остаётся до этапа 8.
- Коммит после каждой задачи.
