# Corporate Mortal Kombat — MVP design

Пародийная браузерная игра. Вместо драки с Шао Каном игрок делает карьеру в
корпорации Внешнего Мира: от стажёра до заместителя Шао Кана по стратегическому
развитию. Некоммерческий проект «поржать», исходник по мотивам поста в Telegram.

## Цели

- Играбельный MVP за один вечер: 15 минут прохождения, три концовки.
- Ноль сборки: открывается двойным кликом по `index.html`, деплоится на
  GitHub Pages как статика.
- Контент отделён от движка: новые события и боссы добавляются в `content.js`
  без правок логики.

## Не входит в MVP

Сохранения, звук, мобильная раскладка, локализация, случайная генерация
событий, 3D.

## Стек

Vanilla JS (ES modules), HTML/CSS, Canvas 2D для экрана боя. Тесты на
встроенном `node --test`. Язык интерфейса и контента — русский.

## Структура файлов

| Файл | Ответственность |
|------|-----------------|
| `index.html` | Разметка двух экранов, шапка со статами, стили |
| `src/state.js` | Чистые функции состояния: применить эффект события, проверить концовки, продвинуть карьеру |
| `src/battle.js` | Чистая боевая формула: урон приёма, ответ босса, исход хода |
| `src/engine.js` | State machine, DOM-биндинги, переходы между экранами |
| `src/render.js` | Canvas: силуэты, полоски, таймер, надписи с тряской |
| `src/render/helmets.js` | Реестр рисовалок шлемов: `HELMETS[name](ctx, x, y, color)` |
| `src/content/index.js` | Собирает `RANKS` из файлов ступеней, экспортирует `MOVES`, `ENDINGS` |
| `src/content/schema.js` | `validateContent(ranks)` |
| `src/content/ranks/NN-<slug>.js` | Одна ступень: должность, два события, босс |
| `test/*.test.js` | Тесты для `state.js`, `battle.js`, `schema.js` |

Разработка идёт поэтапно: план ядра, затем по одному плану на ступень.
Каждая ступень добавляет свой файл в `src/content/ranks/` и свой шлем в
`helmets.js`, движок не трогает.

`state.js` и `battle.js` не трогают DOM и покрываются тестами. `engine.js` и
`render.js` проверяются глазами в браузере.

## Состояние игры

```js
{
  rank: 0,            // индекс ступени 0..5
  stats: { loyalty, reputation, competence, stress },  // 0..100
  flags: Set<string>, // например 'kitana_owes_you'
  week: number,       // счётчик недель для антуража
  step: number,       // позиция внутри ступени: событие 0, событие 1, бой
  seenEvents: Set<string>, // события, уже пройденные хоть раз
  screen: 'start' | 'event' | 'battle' | 'result' | 'ending'
}
```

Начальные статы: Лояльность 30, Репутация 20, Компетентность 30, Стресс 10.
`createInitialState()` в `state.js` — единственный источник стартового
состояния; кнопка «Начать карьеру заново» вызывает её же.

Проверка концовок — одна функция `checkEnding(state)`, которую `engine.js`
вызывает после каждого перехода состояния (после выбора в событии и после
исхода боя). Внутри `applyChoice` и `resolveTurn` концовки не проверяются.

Экран `result` показывает исход боя (надпись на канвасе) и кнопку «Дальше»,
которая ведёт к следующему событию или к концовке.

## Статы

- **Лояльность** — усиливает приём «Согласиться».
- **Репутация** — усиливает «Перевести стрелки» и «Пошутить».
- **Компетентность** — усиливает «Сослаться на данные».
- **Стресс** — растёт от неудач и поражений. Штрафует «Пошутить» и усиливает
  атаку босса (см. формулы). 100 = концовка «Выгорание».

## Карьерная лестница

Шесть ступеней, в каждой ровно два события и один бой:

| # | Должность | События | Босс |
|---|-----------|---------|------|
| 0 | Стажёр | онбординг, первый созвон | Милина (HR): собеседование |
| 1 | Младший специалист Внешнего Мира | KPI, конфликт в чате | Барака (тимлид): код-ревью |
| 2 | Специалист | выбор стороны, корпоратив | Китана: переговоры об альянсе |
| 3 | Руководитель направления | бюджет, найм | Синдел: защита бюджета |
| 4 | Директор департамента | утечка, интрига | Шанг Цунг: подковёрная война |
| 5 | Зам Шао Кана | — | Шао Кан: финальная презентация |

Ступень 5 — только финальный бой (`events: []`), после него концовка.
Пустой список событий разрешён только у последней ступени.

## События

```js
{
  id: 'onboarding',
  title: 'Первый день',
  text: '...',
  choices: [
    { text: '...', effects: { loyalty: +10, stress: +5 }, setFlag: 'x', requiresFlag: 'y' }
  ]
}
```

Выбор применяет `effects` к статам с ограничением 0..100, ставит флаг,
переходит к следующему шагу. Вариант с `requiresFlag` показывается только при
наличии флага; `requiresNotFlag` в MVP нет. Первый вариант каждого события
всегда без `requiresFlag`, чтобы список никогда не был пустым.

Если событие уже есть в `seenEvents` (повтор ступени после поражения), из
`effects` применяется только `stress`, остальные статы не меняются: фермить
статы поражениями нельзя. У события может быть `repeatText`, который
показывается вместо `text` при повторе («Опять первый день»).

Текст события перед боем содержит намёк на слабость босса.

## Боевая механика

Пошаговая. Полоски: у игрока **Уверенность** (100), у босса **Терпение**
(из таблицы ниже). Игрок выбирает один из четырёх приёмов, потом босс делает
ответный ход.

Порядок хода в `resolveTurn(state, move, rng)`: сначала урон игрока; если
Терпение ≤ 0 — возвращается `{outcome: 'win'}` и босс **не** отвечает. Иначе
считается ответ босса; если Уверенность ≤ 0 — `{outcome: 'lose'}`. Иначе
`{outcome: 'continue'}`.

Все функции боя принимают `rng` последним аргументом (по умолчанию
`Math.random`), чтобы тесты передавали `() => 0.9` или `() => 0.1`.

Приёмы и их стат:

| Приём | Тип | Стат |
|-------|-----|------|
| Согласиться | agree | Лояльность |
| Сослаться на данные | data | Компетентность |
| Перевести стрелки | blame | Репутация |
| Пошутить | joke | Репутация |

Урон приёма: `10 + stat * 0.15` (для «Пошутить»: `10 + reputation * 0.15 -
stress * 0.05`, не ниже 3). Умножается на 2, если тип совпадает со `weakness`
босса, на 0.25, если с `immunity`. Результат округляется до целого. Приём по
иммунитету выводит насмешку босса.

Босс каждый ход снимает `boss.attack + stress * 0.05` Уверенности, с шансом
25% (`rng() < 0.25`) делает «спецприём» с уроном ×1.5 и своей репликой.

Ориентир баланса при стате 30: нейтральный удар 14, по слабости 29. Босс с
терпением 120 падает за 5 ходов по слабости и за 8 нейтрально, игрок держится
около 7 ходов. Терпение и атака боссов — единственные числа, которые крутятся
при плейтесте:

| Босс | Терпение | Атака |
|------|----------|-------|
| Милина | 90 | 10 |
| Барака | 110 | 11 |
| Китана | 140 | 12 |
| Синдел | 170 | 13 |
| Шанг Цунг | 210 | 14 |
| Шао Кан | 260 | 16 |

Босс:

```js
{
  id: 'baraka', name: 'Барака', title: 'Тимлид',
  patience: 120, attack: 12,
  weakness: 'agree', immunity: 'joke',
  taunts: { hit: [...], immune: [...], special: [...] },
  silhouette: { helmet: 'blades', color: '#8b1e1e' }
}
```

Исход:

- **Победа**: надпись `FLAWLESS PRESENTATION`, если за бой не было ни одного
  удара по иммунитету и ни одного спецприёма босса, иначе `PROMOTION!!!`.
  Ранг +1, стресс −10, шаг сбрасывается.
- **Поражение**: надпись `PERFORMANCE REVIEW`. Ранг не меняется, стресс +25,
  шаг сбрасывается: события ступени проигрываются заново (см. `seenEvents`),
  затем тот же босс. Проиграть игру можно только через Выгорание.

Финальный бой с Шао Каном имеет пятый приём «Ударить», доступный только там и
показываемый сразу пятой кнопкой. Он мгновенно ведёт к концовке «Fatality».

## Концовки

- **Заместитель Шао Кана** — победа в финальном бою.
- **Выгорание** — Стресс достиг 100 в любой момент.
- **Fatality** — выбран приём «Ударить» на финальной презентации. Пасхалка:
  «Вы вернулись к классическому геймплею. Шао Кан этого не ожидал. Вы тоже.»

Экран концовки: заголовок, текст, кнопка «Начать карьеру заново».

## Экран боя (render.js)

Canvas 960×540, рисуется через `requestAnimationFrame`.

- Две полоски сверху с именами, как в MK. Уменьшение с анимацией за 300 мс.
- Таймер по центру (декоративный, тикает от 99).
- Два процедурных силуэта из примитивов: слева игрок (голова, свитер,
  бейдж), справа босс (широкие плечи, шлем по `silhouette.helmet`:
  `horns`, `blades`, `hair`, `mask`, `skull`). Цвет из `silhouette.color`.
- При уроне силуэт получателя дёргается назад, экран трясётся 200 мс.
- Надписи `ROUND 1`, `FIGHT!`, исход боя — крупным шрифтом с тряской.
- Фон: офис Внешнего Мира — стол, монитор, череп на полке, плакат
  «OUTWORLD».

## Обработка ошибок

Контент валидируется при загрузке: у каждой ступени 2 события и 1 босс
(у последней — 0 событий), у каждого босса `weakness ≠ immunity`, первый
вариант каждого события без `requiresFlag`, все `requiresFlag` ссылаются на
флаги, которые кто-то ставит. При ошибке в консоль и на экран выводится сообщение,
игра не стартует.

## Тестирование

`node --test test/`:

- `state.test.js`: применение эффектов с ограничением 0..100, фильтрация
  вариантов по флагам, повтор события даёт только стресс, продвижение по
  шагам, поражение не меняет ранг, `checkEnding` при стрессе 100,
  `createInitialState` после сброса.
- `battle.test.js`: формула урона со слабостью и иммунитетом, босс не отвечает
  после добивающего удара, завершение боя при нуле полоски, FLAWLESS,
  доступность «Ударить» только у Шао Кана, детерминизм через `rng`.
- `content.test.js`: валидатор пропускает реальный контент и ловит сломанный.

Визуал: открыть `index.html`, пройти одну ступень, снять скриншот боя.
