# Corporate Mortal Kombat — MVP design

Пародийная браузерная игра. Вместо драки с Шао Каном игрок делает карьеру в
корпорации Внешнего Мира: от стажёра до заместителя Шао Кана по стратегическому
развитию. Некоммерческий проект «поржать», исходник по мотивам поста в Telegram.

## Цели

- Играбельный MVP за один вечер: 15 минут прохождения, три концовки.
- Ноль сборки: открывается двойным кликом по `index.html`, деплоится на
  GitHub Pages как статика.
- Контент отделён от движка: новые события и боссы добавляются в `content.js`
  без правок логики.

## Не входит в MVP

Сохранения, звук, мобильная раскладка, локализация, случайная генерация
событий, 3D.

## Стек

Vanilla JS (ES modules), HTML/CSS, Canvas 2D для экрана боя. Тесты на
встроенном `node --test`. Язык интерфейса и контента — русский.

## Структура файлов

| Файл | Ответственность |
|------|-----------------|
| `index.html` | Разметка двух экранов, шапка со статами, стили |
| `src/state.js` | Чистые функции состояния: применить эффект события, проверить концовки, продвинуть карьеру |
| `src/battle.js` | Чистая боевая формула: урон приёма, ответ босса, исход хода |
| `src/engine.js` | State machine, DOM-биндинги, переходы между экранами |
| `src/render.js` | Canvas: силуэты, полоски, таймер, надписи с тряской |
| `src/content.js` | Данные: ступени, события, боссы, приёмы, концовки |
| `test/*.test.js` | Тесты для `state.js` и `battle.js` |

`state.js` и `battle.js` не трогают DOM и покрываются тестами. `engine.js` и
`render.js` проверяются глазами в браузере.

## Состояние игры

```js
{
  rank: 0,            // индекс ступени 0..5
  stats: { loyalty, reputation, competence, stress },  // 0..100
  flags: Set<string>, // например 'kitana_owes_you'
  week: number,       // счётчик недель для антуража
  step: number,       // позиция внутри ступени: событие 0, событие 1, бой
  screen: 'event' | 'battle' | 'ending'
}
```

Начальные статы: Лояльность 30, Репутация 20, Компетентность 30, Стресс 10.

## Статы

- **Лояльность** — усиливает приём «Согласиться».
- **Репутация** — усиливает «Перевести стрелки» и «Пошутить».
- **Компетентность** — усиливает «Сослаться на данные».
- **Стресс** — растёт от неудач и поражений. 100 = концовка «Выгорание».

## Карьерная лестница

Шесть ступеней, в каждой ровно два события и один бой:

| # | Должность | События | Босс |
|---|-----------|---------|------|
| 0 | Стажёр | онбординг, первый созвон | Милина (HR): собеседование |
| 1 | Младший специалист Внешнего Мира | KPI, конфликт в чате | Барака (тимлид): код-ревью |
| 2 | Специалист | выбор стороны, корпоратив | Китана: переговоры об альянсе |
| 3 | Руководитель направления | бюджет, найм | Синдел: защита бюджета |
| 4 | Директор департамента | утечка, интрига | Шанг Цунг: подковёрная война |
| 5 | Зам Шао Кана | — | Шао Кан: финальная презентация |

Ступень 5 — только финальный бой, после него концовка.

## События

```js
{
  id: 'onboarding',
  title: 'Первый день',
  text: '...',
  choices: [
    { text: '...', effects: { loyalty: +10, stress: +5 }, setFlag: 'x', requiresFlag: 'y' }
  ]
}
```

Выбор применяет `effects` к статам с ограничением 0..100, ставит флаг,
переходит к следующему шагу. Вариант с `requiresFlag` показывается только при
наличии флага. Текст события перед боем содержит намёк на слабость босса.

## Боевая механика

Пошаговая. Полоски: у игрока **Уверенность** (100), у босса **Терпение**
(зависит от босса, 100..160). Игрок выбирает один из четырёх приёмов, потом
босс делает ответный ход. Бой заканчивается, когда одна полоска достигает 0.

Приёмы и их стат:

| Приём | Тип | Стат |
|-------|-----|------|
| Согласиться | agree | Лояльность |
| Сослаться на данные | data | Компетентность |
| Перевести стрелки | blame | Репутация |
| Пошутить | joke | Репутация |

Урон приёма: `base 15 + stat * 0.3`, умножается на 2 если тип совпадает со
`weakness` босса, на 0 если с `immunity`. Приём с нулевым уроном выводит
насмешку босса. Босс каждый ход снимает `boss.attack` Уверенности, с шансом 25%
делает «спецприём» с уроном ×1.5 и своей репликой.

Босс:

```js
{
  id: 'baraka', name: 'Барака', title: 'Тимлид',
  patience: 120, attack: 12,
  weakness: 'agree', immunity: 'joke',
  taunts: { hit: [...], immune: [...], special: [...] },
  silhouette: { helmet: 'blades', color: '#8b1e1e' }
}
```

Исход:

- **Победа**: надпись `FLAWLESS PRESENTATION`, если Уверенность не падала ниже
  70, иначе `PROMOTION!!!`. Ранг +1, стресс −10, шаг сбрасывается.
- **Поражение**: надпись `PERFORMANCE REVIEW`. Ранг −1 (не ниже 0), стресс +25,
  шаг сбрасывается, события ступени проигрываются заново.

Финальный бой с Шао Каном имеет пятый приём «Ударить», доступный только там.
Он мгновенно ведёт к концовке «Fatality».

## Концовки

- **Заместитель Шао Кана** — победа в финальном бою.
- **Выгорание** — Стресс достиг 100 в любой момент.
- **Fatality** — выбран приём «Ударить» на финальной презентации. Пасхалка:
  «Вы вернулись к классическому геймплею. Шао Кан этого не ожидал. Вы тоже.»

Экран концовки: заголовок, текст, кнопка «Начать карьеру заново».

## Экран боя (render.js)

Canvas 960×540, рисуется через `requestAnimationFrame`.

- Две полоски сверху с именами, как в MK. Уменьшение с анимацией за 300 мс.
- Таймер по центру (декоративный, тикает от 99).
- Два процедурных силуэта из примитивов: слева игрок (голова, свитер,
  бейдж), справа босс (широкие плечи, шлем по `silhouette.helmet`:
  `horns`, `blades`, `hair`, `mask`, `skull`). Цвет из `silhouette.color`.
- При уроне силуэт получателя дёргается назад, экран трясётся 200 мс.
- Надписи `ROUND 1`, `FIGHT!`, исход боя — крупным шрифтом с тряской.
- Фон: офис Внешнего Мира — стол, монитор, череп на полке, плакат
  «OUTWORLD».

## Обработка ошибок

Контент валидируется при загрузке: у каждой ступени 2 события и 1 босс,
у каждого босса `weakness ≠ immunity`, все `requiresFlag` ссылаются на флаги,
которые кто-то ставит. При ошибке в консоль и на экран выводится сообщение,
игра не стартует.

## Тестирование

`node --test test/`:

- `state.test.js`: применение эффектов с ограничением 0..100, фильтрация
  вариантов по флагам, продвижение по шагам, откат при поражении не ниже 0,
  срабатывание концовки Выгорание.
- `battle.test.js`: формула урона со слабостью и иммунитетом, завершение боя
  при нуле полоски, определение FLAWLESS, доступность «Ударить» только у
  Шао Кана.
- `content.test.js`: валидация контента из раздела выше.

Визуал: открыть `index.html`, пройти одну ступень, снять скриншот боя.
