# Corporate Mortal Kombat — design

Пародийная браузерная игра. Вместо драки с Шао Каном игрок делает карьеру в
корпорации Внешнего Мира: от стажёра до заместителя Шао Кана по стратегическому
развитию. Некоммерческий проект «поржать» по мотивам поста в Telegram.

## Цели

- Качественно проработанная 2D-игра: визуальная новелла между боями,
  кинематографичные пошаговые «бои-переговоры» в интерфейсе Mortal Kombat.
- Единый визуальный стиль: фотореализм как на референсе
  `assets/reference/post-hero-and-shao-kahn.png` — суровые воины Outworld в
  типовом офисе с черепами. Контраст «пафос против офисной рутины» и есть шутка.
- 15–20 минут прохождения, три концовки.
- Ноль сборки: статика, открывается двойным кликом по `index.html`, деплоится
  на GitHub Pages.
- Контент и ассеты отделены от движка: новая ступень добавляется файлом данных
  и набором картинок, движок не трогается.

## Не входит

Сохранения прогресса, мобильная раскладка, локализация, случайная генерация
событий, покадровые спрайтшиты, мультиплеер.

## Стек

- Vanilla JS (ES modules), HTML/CSS, Canvas 2D для экрана боя. Без
  фреймворков и бандлера.
- Тесты на встроенном `node --test`.
- Генерация ассетов: OpenRouter Image API (`POST /api/v1/images/generations`),
  основная модель `bytedance-seed/seedream-5-0-pro` (до 14 референсов, `seed`,
  разрешение 1K/2K, произвольный `aspect_ratio`), запасная
  `google/gemini-3-pro-image`. Модель — поле в манифесте, меняется без правок
  кода. Скрипт генерации на Node. Постобработка (обрезка фона, ресайз, WebP)
  на Python 3 + Pillow.
- Ключ в `.env` в корне: `OPENROUTER_API_KEY=...`. Файл в `.gitignore`.
- Язык интерфейса и контента — русский. Надписи-баннеры в бою — английские,
  как в оригинале (`FIGHT!`, `FLAWLESS PRESENTATION`).

## Экраны

State machine в `engine.js`, поле `state.screen`:

```
start → event ⇄ battle → result → event | ending
                  ↑                        ↓
                  └──── restart ───────────┘
```

- **start** — титульный экран: сгенерированный арт (герой и Шао Кан
  пожимают руки), логотип «CORPORATE MORTAL KOMBAT» в стиле драконьей эмблемы,
  но с офисным зажимом для бумаг, кнопка «Начать карьеру». Первый клик
  разблокирует Web Audio.
- **event** — визуальная новелла: фон локации на весь экран, портрет
  собеседника справа с эмоцией, диалоговое окно снизу с печатанием текста
  (клик — показать целиком), 2–4 карточки выбора появляются после текста.
  Сверху HUD.
- **battle** — канвас 1280×720, масштабируется под окно с сохранением
  пропорций. Смотри раздел «Экран боя».
- **result** — поверх канваса: баннер исхода, изменение статов, кнопка «Дальше».
- **ending** — иллюстрация концовки, заголовок, текст, кнопка «Начать карьеру
  заново».

HUD (на экранах event и result): должность, неделя, четыре стата полосками
с анимацией изменения и всплывающими `+10`/`−5`.

## Состояние игры

```js
{
  rank: 0,            // индекс ступени 0..5
  step: 0,            // событие 0, событие 1, затем бой
  week: 1,
  screen: 'start' | 'event' | 'battle' | 'result' | 'ending',
  stats: { loyalty, reputation, competence, stress },  // 0..100
  flags: Set<string>,      // например 'kitana_owes_you'
  seenEvents: Set<string>  // события, пройденные хоть раз
}
```

Начальные статы: Лояльность 30, Репутация 20, Компетентность 30, Стресс 10.
`createInitialState()` — единственный источник стартового состояния; кнопка
«Начать карьеру заново» вызывает её же.

`checkEnding(state, ranks)` — одна функция, которую `engine.js` вызывает
после каждого перехода (после выбора в событии и после исхода боя).
Возвращает `'burnout' | 'promotion' | null`. Внутри `applyChoice` и
`resolveTurn` концовки не проверяются.

## Статы

- **Лояльность** — усиливает приём «Согласиться».
- **Репутация** — усиливает «Перевести стрелки» и «Пошутить».
- **Компетентность** — усиливает «Сослаться на данные».
- **Стресс** — растёт от неудач и поражений, штрафует «Пошутить», усиливает
  атаку босса. 100 = концовка «Выгорание».

|---|-----------|---------|---------|------|

| 2 | Специалист | Кухня с кулером | выбор стороны, корпоратив | Китана: переговоры об альянсе |
| 3 | Руководитель направления | Зал совета | бюджет, найм | Синдел: защита бюджета |
| 4 | Директор департамента | Серверная-подземелье | утечка, интрига | Шанг Цунг: подковёрная война |

и для её боя.

## События

```js
{
  id: 'onboarding',
  title: 'Первый день',
  background: 'bg_openspace',            // id из манифеста
  speaker: { portrait: 'pt_mileena_neutral', name: 'Милина' },
  text: '...',
  repeatText: '...',                     // опционально, при повторе ступени
  choices: [
    { text: '...', effects: { loyalty: +10, stress: +5 },
      setFlag: 'x', requiresFlag: 'y',
      reaction: { portrait: 'pt_mileena_angry', text: '...' } }  // опционально
  ]
}
```

Выбор применяет `effects` с ограничением 0..100, ставит флаг. Если у выбора
есть `reaction`, портрет меняется и печатается ответная реплика, затем кнопка
«Дальше». Вариант с `requiresFlag` виден только при наличии флага;
`requiresNotFlag` в MVP нет. Первый вариант события всегда без `requiresFlag`.

Повтор ступени после поражения: из `effects` применяется только `stress`,
показывается `repeatText`, если есть. Фермить статы поражениями нельзя.

Текст события перед боем содержит намёк на слабость босса.

## Боевая механика

Пошаговая. У игрока **Уверенность** (100), у босса **Терпение** из таблицы.
Игрок выбирает приём, смотрит анимацию, затем ход босса.

`resolveTurn(battle, move, stats, boss, rng = Math.random)`:
сначала урон игрока; если Терпение ≤ 0 — `{outcome: 'win'}`, босс не
отвечает. Иначе ответ босса; если Уверенность ≤ 0 — `{outcome: 'lose'}`.
Иначе `{outcome: 'continue'}`. Все функции боя принимают `rng` последним
аргументом, тесты передают `() => 0.9` или `() => 0.1`.

| Приём | id | Стат |
|-------|----|------|
| Согласиться | agree | Лояльность |
| Сослаться на данные | data | Компетентность |
| Перевести стрелки | blame | Репутация |
| Пошутить | joke | Репутация, штраф от Стресса |

Урон приёма: `10 + stat × 0.15`; для «Пошутить» `10 + reputation × 0.15 −
stress × 0.05`, не ниже 3. Множитель 2 при совпадении с `weakness`, 0.25 при
совпадении с `immunity`. Округление до целого. Удар по иммунитету выводит
насмешку босса.

Босс снимает `attack + stress × 0.05`, с шансом 25% (`rng() < 0.25`)
спецприём ×1.5 со своей репликой и особой анимацией.

Ориентир при стате 30: нейтральный удар 15, по слабости 29. Босс с терпением
120 падает за 5 ходов по слабости и за 8 нейтрально; игрок держится около 7
ходов. Единственные числа для плейтеста:

| Босс | Терпение | Атака | Слабость | Иммунитет |
|------|----------|-------|----------|-----------|
| Милина | 90 | 10 | joke | blame |
| Барака | 110 | 11 | agree | joke |
| Китана | 140 | 12 | data | agree |
| Синдел | 170 | 13 | blame | joke |
| Шанг Цунг | 210 | 14 | data | blame |
| Шао Кан | 260 | 16 | agree | data |

Босс:

```js
{
  id: 'baraka', name: 'Барака', title: 'Тимлид',
  patience: 110, attack: 11, weakness: 'agree', immunity: 'joke',
  final: false,
  sprites: { idle: 'sp_baraka_idle', attack: 'sp_baraka_attack',
             hurt: 'sp_baraka_hurt', defeated: 'sp_baraka_defeated' },
  portraits: { neutral: 'pt_baraka_neutral', angry: 'pt_baraka_angry' },
  arena: 'bg_meeting_room',
  intro: 'Реплика перед боем',
  lines: { hit: [...], immune: [...], special: [...], defeated: [...] }
}
```

Исход:

- **Победа**: `FLAWLESS PRESENTATION`, если за бой не было ударов по
  иммунитету и спецприёмов босса, иначе `PROMOTION!!!`. Ранг +1, стресс −10.
- **Поражение**: `PERFORMANCE REVIEW`. Ранг не меняется, стресс +25, ступень
  повторяется с события 0. Проиграть игру можно только через Выгорание.

Финальный бой (`final: true`) добавляет пятый приём «Ударить», видимый сразу.
Он мгновенно ведёт к концовке «Fatality».

## Концовки

- **Заместитель Шао Кана** — победа в финале. Иллюстрация: герой в тронном
  кабинете за столом с табличкой «Заместитель по стратегическому развитию».
- **Выгорание** — Стресс 100. Иллюстрация: герой спит лицом на клавиатуре,
  вокруг черепа и стикеры.
- **Fatality** — приём «Ударить». Текст: «Вы вернулись к классическому
  геймплею. Шао Кан этого не ожидал. Вы тоже.» Иллюстрация: герой в
  разорванном твидовом пиджаке с кулаком, Шао Кан на полу, разбитый монитор.

## Экран боя

Канвас 1280×720. Слои снизу вверх: фон арены с лёгким параллаксом от камеры,
тень под бойцами, спрайты, партиклы и цифры урона, HUD, баннеры, виньетка.

**Спрайты.** У каждого бойца четыре позы: `idle`, `attack`, `hurt` и
`defeated` (у героя вместо `defeated` — `win`). Idle дышит: масштаб по Y
±1.5% с периодом 2 с. Смена позы — мгновенная, движение делает камера и
твины позиции.

**Ход игрока.** Кнопка приёма → герой шагает вперёд на 80 px за 150 мс (поза
`attack`), камера подъезжает на 8% к боссу, вспышка белого 60 мс, у босса
поза `hurt` и отскок назад 40 px, партиклы (бумажки, искры) от точки удара,
летящая цифра урона, тряска 200 мс с амплитудой от урона. Полоска Терпения
уменьшается за 300 мс с «призрачным» остатком, как в MK. Реплика босса
из `lines` появляется в облачке над ним. По иммунитету — удар без вспышки,
цифра серая, тряски нет, реплика из `lines.immune`.

**Ход босса.** Симметрично: босс шагает, герой в `hurt`, тряска сильнее.
Спецприём: экран темнеет до 40%, красная вспышка, крупная реплика по центру.

**Баннеры.** `ROUND 1` (декоративный), `FIGHT!`, `FLAWLESS PRESENTATION`,
`PROMOTION!!!`, `PERFORMANCE REVIEW`, `FINISH HIM` (когда Терпение Шао Кана
< 15%). Шрифт — тяжёлый гротеск с металлическим градиентом, появление
масштабом 3→1 за 250 мс с тряской. Диктор озвучивает баннер через
`speechSynthesis`, если доступно.

**Победа.** Босс в `defeated`, герой в `win`, замедление до 0.5× на 1 с,
баннер, конфетти из бумажек. **Поражение.** Герой в `hurt` оседает, серый
фильтр, баннер.

**HUD боя.** Две полоски сверху с именами и должностями, портреты бойцов по
краям, таймер по центру (декоративный, тикает от 99, при 0 просто
останавливается). Внизу карточки приёмов с названием и статом; при наведении
подсказка: сколько урона ожидать без учёта слабости.

## Звук

`src/audio.js` синтезирует всё через Web Audio, файлов нет:

- `hit` — шумовой удар с низкой синусоидой, громкость от урона.
- `immune` — короткий глухой «бум» с обрывом.
- `special` — низкий гул и щелчок.
- `whoosh` — фильтрованный шум при шаге вперёд.
- `bar` — тик уменьшения полоски.
- `banner` — гонг: синус с быстрым спадом и реверберацией через свёртку.
- `type` — тихий клик на каждую букву печатания.
- `win` — трёхнотный фанфар, `lose` — нисходящий тон.

Диктор: `speechSynthesis` с английским голосом, pitch 0.3, rate 0.8, для
баннеров. Если API недоступно — молча. Кнопка выключения звука в HUD,
состояние в `localStorage`.

## Ассеты

Все картинки перечислены в `assets/manifest.json`:

```json
{
  "id": "sp_baraka_idle",
  "kind": "sprite" | "portrait" | "background" | "illustration",
  "file": "assets/img/sprites/baraka_idle.webp",
  "size": [700, 900],
  "prompt": "...",
  "reference": ["assets/reference/post-hero-and-shao-kahn.png"]
}
```

Полный набор:

| Тип | Штук | Размер | Описание |
|-----|------|--------|----------|
| Герой, спрайты | 4 | 700×900 | idle, attack, hurt, win |
| Герой, портрет | 2 | 512×512 | neutral, worried |
| Боссы, спрайты | 6 × 4 = 24 | 700×900 | idle, attack, hurt, defeated |
| Боссы, портреты | 6 × 2 = 12 | 512×512 | neutral, angry |
| Второстепенные портреты | 2 | 512×512 | Рептилия из IT-поддержки, Джакс из охраны |
| Фоны локаций | 6 | 1920×1080 | по одному на ступень |
| Иллюстрации | 4 | 1920×1080 | титул и три концовки |

Итого 54 картинки. Стоимость на Seedream 5.0 Pro — несколько центов за
картинку, с запасом на пересъёмку ×2 укладываемся в 10 долларов.

**Единство стиля.** Каждый промпт начинается с общего префикса стиля
(фотореалистичный кинематографичный кадр, мягкий офисный свет, приглушённые
тёплые тона, детализация как на референсе) и передаёт референс-картинку из
поста. Спрайты одного персонажа генерируются с его портретом как вторым
референсом, чтобы лицо и костюм не плавали между позами.

**Спрайты** запрашиваются в полный рост на однородном ярко-зелёном фоне
`#00FF00`, ракурс три четверти, свет слева. `tools/postprocess.py` вырезает
хромакей с мягкой кромкой, кадрирует по контенту с отступом, приводит к
размеру, сохраняет WebP. Герой всегда смотрит вправо, боссы влево; если
модель ошиблась — флаг `flip` в манифесте.

**Пайплайн.** `node tools/gen-assets.mjs [--only id] [--force]` идёт по
манифесту, пропускает существующие файлы, для каждого недостающего шлёт запрос
в Image API: `model`, `prompt`, `aspect_ratio` (из `size`), `resolution: "2K"`
для фонов и `"1K"` для остального, `seed` из манифеста (один на персонажа,
чтобы позы не расходились), референсы как data-URL в `input_references`.
Ответ содержит картинку в base64; сырой PNG сохраняется в `assets/raw/`,
затем вызывается постобработка. Ошибки сети — 3 повтора с паузой. Брак пересъёмом
`--only id --force`. Сырые PNG в `.gitignore`, в репо живут только WebP.

**Загрузка в игре.** `src/assets.js` читает манифест, грузит картинки
параллельно, показывает прогресс на титульном экране. Отсутствующая картинка
заменяется цветным прямоугольником с id — игра не падает, брак виден.

## Обработка ошибок

`validateContent(ranks, manifest)` при старте: у каждой ступени 2 события и
1 босс (у последней 0 событий); `weakness ≠ immunity`; первый вариант события
без `requiresFlag`; каждый `requiresFlag` кем-то ставится; каждый id
ассета из контента есть в манифесте; ровно один босс `final: true`, и он
последний. При ошибке — список на экране, игра не стартует.

Загрузка ассетов: ошибка одной картинки логируется, ставится заглушка,
игра продолжается.

## Тестирование

`node --test test/`:

- `state.test.js`: эффекты с ограничением 0..100, фильтрация по флагам, повтор
  события даёт только стресс, шаги и переход к бою, поражение не меняет ранг,
  `checkEnding`, `createInitialState`.
- `battle.test.js`: формула урона со слабостью, иммунитетом и штрафом за
  стресс; босс не отвечает после добивающего; исходы; FLAWLESS; «Ударить»
  только у финального босса; детерминизм через `rng`.
- `schema.test.js`: валидатор пропускает реальный контент, ловит каждое
  нарушение из списка выше.
- `tween.test.js`: интерполяция, easing на границах, завершение очереди.
- `manifest.test.js`: каждый файл из манифеста существует и не пустой, id
  уникальны, каждый id, на который ссылается контент, есть в манифесте.

Визуал и звук: ручной прогон в браузере, скриншоты боя и события
складываются в `docs/screenshots/` на каждом этапе.

## Этапы

Каждый этап — отдельный план в `docs/superpowers/plans/`, даёт работающую
игру и проходит ревью отдельно.

1. **Ядро.** Каркас, состояние, бой, валидатор, движок экранов, VN-экран и
   канвас с прямоугольниками вместо спрайтов, звук, HUD, один тестовый босс.
2. **Пайплайн ассетов и герой.** Манифест, генерация, постобработка, загрузчик,
   спрайты и портреты героя, титульный экран, иллюстрации концовок,
   финальный вид канваса со всеми эффектами на реальных спрайтах.
3. **Ступень 0.** Милина: события, бой, фон, спрайты, портреты.
4. **Ступень 1.** Барака.
5. **Ступень 2.** Китана.
6. **Ступень 3.** Синдел.
7. **Ступень 4.** Шанг Цунг и Рептилия.
8. **Финал.** Шао Кан, «Ударить», FINISH HIM, Fatality, Джакс, плейтест
   баланса всей лестницы, деплой на GitHub Pages.
